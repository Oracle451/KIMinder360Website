KIMinder360 Mobile App

Technologies & Tools

  • Kotlin: Chosen as the primary programming language for its concise syntax, null safety, and interoperability with Java libraries. As the preferred language for Android development by Google, it provides broad compatibility and support for native Android applications. It will be used for all app logic, including randomization algorithms and notification scheduling, helping reduce bugs and improve readability compared to Java.

  • Android Studio: Our IDE of choice for its integrated tools like the Android Profiler and emulator support. It facilitates MVVM implementation, UI prototyping with Jetpack Compose, and debugging, streamlining the development workflow. As the official Android development environment, it offers many features that simplify starting Android development.

  • Room Persistence Library: Selected for local database management due to its abstraction over SQLite, compile time query verification, and seamless integration with LiveData/ViewModel. It handles directive storage and offline data integrity, ensuring zero loss during app restarts.

  • Android NotificationManager and WorkManager: Used for push notifications and background scheduling. NotificationManager delivers tappable alerts, while WorkManager ensures reliable, battery-efficient task execution (directive randomization), respecting device constraints like Do Not Disturb.

  • Firebase (Optional Integration): Incorporated for cloud features like Realtime Database for shared directives. Chosen for its easy Android SDK, real time syncing, and security rules, enabling future scalability without overcomplicating the MVP.

  • GitHub: Our version control and repository tool, selected for collaboration features like pull requests and issue tracking. It hosts the codebase and facilitates collaboration and review.
